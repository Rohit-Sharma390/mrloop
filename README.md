# MrLoop website
Static site: open index.html (or run `npx serve .`). No build step, no dependencies.

## Edit content in ONE place: js/content.js
- Instagram URL + handle (the only social link; used in nav, social section and footer)
- Flavours (hero ring, menu): name, description, price, image path. Add/remove rows freely (hero adapts, 3+ recommended; 6 designed)
- Combos (churro + ice cream)
Other placeholders in index.html: address, hours, phone, email, Google Maps link, about copy (search "PLACEHOLDER").
Colour tokens at the top of css/styles.css are PROVISIONAL estimates.
